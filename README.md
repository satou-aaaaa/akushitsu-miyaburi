# 悪質商法みやぶり

まちの相談窓口に来た人の話を読んで、悪質商法の手口を見抜き、どうすればよいか（断り方・クーリング・オフ・相談先）を選ぶ1日5件の学習ゲームです。前もって知らなくても、遊ぶうちに手口の見分け方とクーリング・オフの日数が身につきます。

遊ぶ: <https://satou-aaaaa.github.io/akushitsu-miyaburi/>

## 遊び方

- 今日の5件（だれでも同じ・1日1回）：手口は？ → どうする？ → クーリング・オフの最後の日は？ → どうする？ → クーリング・オフできる？
- 上級（ヒントなし3件）・練習（何度でも）・とことん（まちがえても続き、「ここで降りる」まで）・おさらい（まちがえた問題）
- 手口帳（13の手口の見分け方と断り方）・実績・カレンダー（取りこぼした過去7日をあとから）
- 時間制限なし。記録は遊ぶ人のブラウザ（localStorage）だけに置き、外へ送りません。

## 中身の出どころ

人物と話は作り話です。手口と決まりは、消費者庁「特定商取引法ガイド」・国民生活センター・自治体や警察の消費生活のページにもとづいています（一覧は `data.js` の `SRC` と、ゲームの「このゲームについて」）。

- クーリング・オフは、書面を受け取った日を1日目に数えて、訪問販売・電話勧誘販売・エステなど長く通う契約・訪問購入は8日、マルチ商法（連鎖販売取引）・内職商法（業務提供誘引販売取引）は20日。
- 通信販売・自分から店に出向いたふつうの契約（1か月・5万円をこえるエステなど長く通う契約は別）・乗用車・現金で3,000円未満の買い物には、クーリング・オフはありません。
- 注文していない商品は、払わなくてよく、すぐに処分できます（2021年7月6日から）。

このゲームは法律相談ではありません。こまったときは、消費者ホットライン 188 に電話すると、近くの消費生活センターなどの相談窓口につながります。
